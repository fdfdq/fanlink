导入与导出设置

将所有个性化设置导出为 JSON 文件备份，或从备份文件恢复设置。

导入设置将覆盖当前所有设置，包括主题、布局、便签、搜索历史等，此操作不可撤销。建议先导出当前设置作为备份。

Fanlink 3.05

功能更新记录

  • 极简模式新增 Dock 栏：底部透明 Dock，默认含启动台，可固定网站、拖拽排序、右键删除。
  • 启动台：点击 Dock 启动台图标，背景虚化弹出所有收录网站，支持右键固定到 Dock。
  • 设置新增"导入与导出"选项卡，支持 JSON 格式备份和恢复全部设置。
  • 设置选项卡顺序优化，外观内设置项按使用频率重排。
  • 极简模式下自动禁用不相关的设置项，关闭极简模式后恢复。
  • 星期显示支持多语言，根据当前界面语言自动切换星期格式。
  • 网络图片壁纸功能，输入图片网址即可将其设置为背景。
  • 多语言支持，包含简体中文、繁体中文、英语和俄语。
  • 地址栏指令系统，支持 /language 快速切换语言，以及 /cft 跳转分类。
  • Help 弹窗重新设计，采用毛玻璃效果。
  • 便签支持拖拽功能。
  • 多色主题切换，提供六种预设配色方案。
  • 暗黑模式、高对比度模式、自动隐藏底栏等正式功能。
  • 开发者设置保留"启用旧版样式"实验性功能。
  • 自定义滚动条全面升级。
  • Ctrl+Shift+D 快捷键，打开开发者设置面板。
  • 完整地址栏指令系统，覆盖所有功能。
  • 搜索历史：输入框模糊匹配、下拉面板、管理面板。
  • 浏览器扩展版本，新标签页自动设置为 Fanlink。
  • 每日一言：从 text.txt 奇数行随机选一句显示在搜索框，可在设置中开关。
  • 搜索历史支持自定义匹配阈值（0-100%）。
  • 超级极简模式：隐藏所有内容，仅保留居中搜索框、壁纸、模糊效果和右上角设置。
  • 小组件系统（重磅更新）：极简模式下支持虚拟网格布局，左上角编辑开关可拖拽调整时钟和搜索栏位置，右键删除小组件，空白处右键打开小组件市场添加新组件。
  • 极简模式时钟改为普通模式样式，跟随主题色显示。
