# Fanlink - 现代化浏览器起始页

Fanlink 是一个美观、高效、高度可定制的浏览器起始页，旨在为用户提供极致的上网体验和便捷的导航服务。

## ✨ 主要特性

### 🎨 现代化界面设计
-**网格布局视图**：图标在上、文字在下的清晰展示方式 
-**响应式设计**：完美适配各种屏幕尺寸和设备 
-**视觉优化**：清爽现代的界面，提供直观的视觉体验 

### ⚡ 高效搜索体验
-**一键直达搜索**：输入关键词直接跳转搜索引擎 
-**流程简化**：移除冗余中间页面，提升搜索效率 
-**流畅自然**：优化后的搜索流程更加快速便捷 

### 🔧 高度个性化
-**个性化设置面板**：集成边栏显示控制等核心功能 
-**便捷操作**：告别繁琐设置，一键隐藏/显示分类栏 
-**统一布局**：设置选项分类合理，操作直观便捷 

### 📱 多平台支持
-**网页版**：在线访问，数据云端同步 
-**桌面版**：本地应用，更稳定性能表现

## 📥 安装与使用

1.**设置为浏览器主页** 
   - 打开浏览器设置
   - 将主页设置为：`https://fdfdq.rth2.xyz/fanlink.html | https://fdfdq.github.io/fanlink/fanlink 3.0x.html`

2.**个性化配置** 
   - 点击设置图标进入个性化面板
   - 调整布局、主题、边栏显示等选项
   - 添加常用网站收藏

3.**开始使用** 
   - 使用搜索框快速搜索
   - 通过网格布局快速访问收藏网站
   - 使用便签功能记录重要信息

## 🔄 版本更新

### 当前版本：v3.04
最新更新内容：
  星期显示支持多语言，根据当前界面语言自动切换星期格式。
  网络图片壁纸功能，输入图片网址即可将其设置为背景，支持主流图片格式。
  多语言支持，包含简体中文、繁体中文、英语和俄语，界面文字随语言设置动态更新。
  地址栏指令系统，支持 /language 快速切换语言，以及 /cft 跳转分类。
  Help 弹窗重新设计，采用毛玻璃效果，更清晰地展示所有可用快捷指令。
  便签支持拖拽功能，可自由调整便签在屏幕上的位置。
  多色主题切换，提供六种预设配色方案，满足不同视觉偏好。
  暗黑模式、高对比度模式、自动隐藏底栏、搜索框圆角、按钮圆角、侧边栏透明度等正式功能现已在个性化设置中提供。
  开发者设置保留“启用旧版样式”实验性功能，供用户切换回 Fanlink 3.01 风格。
  自定义滚动条全面升级，更宽、更明显，匹配整体视觉风格，应用于所有滚动区域。
  Ctrl+Shift+D 快捷键，首次输入 /dev 后即可使用该快捷键快速打开开发者设置面板。
  新增网站：全历史（学习分类）、Carbon（工具分类）、TinyPNG（工具分类）。
  新版定制下拉菜单重构，采用 fixed 定位并带有边缘检测，确保不会跑出屏幕，圆角独立且不受按钮圆角影响。
  背景图片算法优化为 cover 填充模式，且固定不随滚动条滚动。
